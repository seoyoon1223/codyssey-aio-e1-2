# Git clone and pull practice

This working copy was cloned from the public submission repository to verify that the pushed project can be obtained independently.

```powershell
git clone https://github.com/seoyoon1223/codyssey-aio-e1-2.git missions/aio-e1/clone-practice/codyssey-aio-e1-2
```

The clone initially contained the pushed `main` history through commit `3b97800`. This file was then added in the clone, committed, and pushed. Pulling `origin/main` from the primary working copy brings the new file and commit into that checkout.
